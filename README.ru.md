Заменяет строку статистики под полем ввода сообщения в настольном приложении DSH на настраиваемую строку состояния: поля, порядок, цены по моделям и валюта — всё настраивается, с оценкой затрат в реальном времени по официальным тарифам DeepSeek для пиковых и непиковых часов.

https://github.com/user-attachments/assets/5a4f7fd8-a445-490d-a557-1ec840c611df

## Возможности

- **9 необязательных полей плюс кольцо контекста**: занятость контекста (кольцо в начале панели), проверка пиковых/непиковых часов, ходы и шаги, доля попаданий в кэш, скорость вывода, TTFT, время работы, стоимость текущего хода, стоимость сессии, баланс
- **Нажмите на поле, чтобы увидеть подробности**:

  | Поле | Содержимое |
  | --- | --- |
  | Кольцо контекста (начало панели) | Системный промпт / определения инструментов / сообщения |
  | Проверка пиковых/непиковых часов | Тепловая карта использования: день / неделя / месяц / год |
  | Ходы и шаги | Сжатия контекста / внедрённые навыки / вызовы инструментов |
  | Комбинированные попадания | Текущий ход / максимальная / минимальная доля попаданий в кэш |
  | TPS | Текущий ход / максимальная / минимальная скорость |
  | TTFT | Текущий ход / минимальная / максимальная задержка до первого токена |
  | Время работы | Время ожидания / время модели / вызовы инструментов |
  | Стоимость текущего хода | Разбивка токенов для текущего хода |
  | Стоимость сессии | Накопленная разбивка токенов для этой сессии |
  | Баланс | Пополненный баланс / предоставленный баланс / остаток квоты |

- **Детализация данных сессии**: сжатия контекста отмечают узел, на котором произошли, «внедрённые навыки» считают навыки, внедрённые в этой сессии, а вызовы инструментов перечисляют каждый инструмент, использованный сессией, с числом вызовов; нажмите на заголовок, чтобы вернуться наверх
- **Проверка версии и обновление**: DSH проверяет наличие последней версии при запуске, показывает подсказку рядом с пунктом навигации «Строка состояния», когда она доступна, и предлагает кнопку обновления в один клик в настройках
- **Поддержка на GitHub**: кнопка открывает страницу проекта на GitHub, где вы можете поставить проекту звезду.
- **Оценка затрат**: цена рассчитывается по официальным правилам пиковых/непиковых часов; каждый вызов вычисляется по моменту, когда он произошёл, и использованной модели
- **Книга цен**: собственные цены, необязательное разделение на пиковые/непиковые и переключатель валют CNY / USD
- **Также**: автоматические обновления праздников, баланс обновляется каждую минуту, 8 языков интерфейса (简体中文 / English / 日本語 / Español / Français / Deutsch / Русский / Português)

## Установка

В настольном приложении DSH откройте **Плагины → Добавить плагин** и установите по имени пакета:

```
dsh-desktop-statusbar
```

Где реестр npm недоступен, тот же диалог предлагает зеркало для материкового Китая в качестве источника установки. URL репозитория GitHub также принимается:

```
https://github.com/raphael-y7/dsh-desktop-statusbar
```

Командная строка:

```powershell
dsh plugin --profile desktop add dsh-desktop-statusbar
```

### Установка из npm

Оба способа выше устанавливают из реестра npm; имя пакета — `dsh-desktop-statusbar`. Чтобы проверить текущую версию в npm:

```powershell
npm view dsh-desktop-statusbar version
```

### Когда встроенный обновлятор даёт сбой

Встроенная кнопка обновления в один клик может не сработать в некоторых сборках для настольных систем: она либо не реагирует, либо сообщает об ошибке. В этом случае используйте официальный вход установки и **добавьте `@version` к имени пакета**, чтобы установить точную версию:

```powershell
dsh plugin --profile desktop add dsh-desktop-statusbar@3.0.5
```

Та же строка работает в панели плагинов: введите `dsh-desktop-statusbar@3.0.5` в поле **Добавить плагин**.

Используйте текущую последнюю версию (указанную на странице релиза или в выводе `npm view` выше). Закрепление версии также гарантирует, что **вы установите именно целевую сборку**, избегая устаревшего кэшированного пакета.

Также указан на [dshmarket](https://awesome-dsh-plugin.com/p/raphael-y7/dsh-desktop-statusbar/), [dshfind](https://dshfind.com/zh/plugins/raphael-y7/dsh-desktop-statusbar) и [1024Store](https://deepseek1024.com/plugins/Rapheal-Y7/dsh-desktop-statusbar).

## Использование

Откройте **Настройки → Строка состояния**:

![Settings page](docs/settings.en.png)

- **Занятость контекста**: кольцо в начале панели — прогресс показывает долю использованного контекста, разрыв отмечает порог сжатия, а цвет показывает состояние выполнения (простой-серый / выполняется-зелёный / субагент работает-синий / более глубокий субагент работает-фиолетовый / ошибка-красный / ожидание одобрения-янтарный)
- **Поля статистики**: установка флажка управляет только видимостью, поэтому снятие флажка скрывает поле, не перемещая его; перетащите маркер справа, чтобы изменить порядок; «Сбросить настройки» восстанавливает заводской порядок
- **Пользовательские цены моделей**: введите имя модели и нажмите «Добавить», чтобы создать запись; «Изменить» открывает редактор, и изменения записываются при сохранении; установите флажок «Цены пиковых/непиковых часов», чтобы разделить по времени суток, иначе применяется единая цена на весь день
- **Валюта**: CNY или USD в правом верхнем углу редактора. При переключении две встроенные модели заменяются официальными справочными ценами этой валюты (отредактированные записи сохраняются), и символ в полях стоимости меняется; баланс следует за валютой, сообщаемой API
- **Праздники**: автоматически получает и записывает расписание следующего года после 31 декабря каждого года
- **Баланс**: обновляется раз в минуту

### Правила тарификации

Пиковые часы — **09:00–12:00 и 14:00–18:00 по пекинскому времени, с понедельника по пятницу**, а непиковые тарифы составляют половину пиковых; китайские государственные праздники и выходные тарифицируются по непиковому тарифу весь день (в соответствии с [официальной документацией](https://api-docs.deepseek.com/quick_start/pricing), проверено в сентябре 2026 г.).

## Запрос баланса транзитного узла

При запросе баланса строка состояния выбирает способ запроса в зависимости от **платформы, фактически используемой текущей сессией**; возможны два случая: автоматическое сопоставление и ручная настройка.

### 1. Автоматическое сопоставление

Если транзитный узел настроен как обычный provider на странице DSH **Модели** (с baseURL и ключом API), плагин с помощью этого ключа параллельно опрашивает следующие распространённые эндпоинты баланса; как только отвечает любой разбираемый эндпоинт, баланс отображается без дополнительной настройки:

- `/v1/usage`
- `/v1/user/self`, `/api/user/self`, `/api/v1/user/self`
- `/api/usage`
- `/v1/dashboard/billing/credit_grants`
- `/v1/credits`

Если эндпоинт баланса сайта относится к одной из указанных стандартных форм и доступен для чтения через `Authorization: Bearer <ключ API>`, баланс отображается автоматически.

### 2. Ручная настройка

В любом из следующих случаев необходимо добавить запись платформы в **Настройки → Строка состояния → Пользовательские цены моделей → Платформа** и указать эндпоинт и учётные данные:

- у provider на странице **Модели** не настроен baseURL;
- эндпоинт баланса или способ аутентификации не относится к стандартной форме (например, New API требует дополнительный заголовок запроса с идентификатором пользователя);
- структура ответа эндпоинта не может быть разобрана автоматически.

Поля определены следующим образом:

| Поле | Описание | Пример |
| --- | --- | --- |
| Заголовок запроса | Имя заголовка запроса, используемого для идентификатора пользователя; аутентификация по токену всегда использует `authorization: Bearer` и не требует заполнения | `New-Api-User` |
| Идентификатор пользователя | Идентификатор пользователя для указанного выше заголовка запроса | `12345` |
| Токен | New API: указать «токен доступа» (системный токен доступа в личных настройках); Sub2API: указать «токен входа»; обычный транзитный узел: указать ключ `sk-`, используемый для вызова моделей | `sk-...` |
| Адрес запроса баланса | Полный URL эндпоинта баланса | `https://example.com/api/user/self` |
| Поле баланса | Символ валюты, путь к полю и делитель в формате `<валюта><путь к полю> / <делитель>` | `$data.quota / 500000` |
| Применимые модели | Модели, относящиеся к этой платформе | — |
| Множитель стоимости | Множитель ценообразования, по умолчанию 1 | `1` |

#### Пример 1: сайт, совместимый с New API

- Адрес запроса баланса: `https://example.com/api/user/self`
- Поле баланса: `$data.quota / 500000` (этот сайт считает 500000 квоты за 1 юань)
- Токен: токен доступа, созданный в личных настройках (не ключ вызова моделей)
- Заголовок запроса: `New-Api-User`; идентификатор пользователя: идентификатор пользователя аккаунта

#### Пример 2: сайт Sub2API

Эндпоинт баланса сайтов Sub2API обычно имеет одну из двух следующих форм; выбирайте по фактическому состоянию сайта:

- Поддерживается совместимый с OpenAI `GET /v1/usage` (аутентификация ключом модели `sk-`): обычно сопоставляется автоматически, ручная настройка не требуется; если совпадения нет, укажите в качестве токена этот ключ `sk-`, а в качестве адреса запроса баланса — `https://example.com/v1/usage`.
- Доступен только консольный эндпоинт (эндпоинт находится по пути `/api/v1/*` и требует сессии входа в консоль): укажите в качестве адреса запроса баланса консольный эндпоинт баланса этого сайта (по фактическому состоянию сайта), **в качестве токена укажите «токен входа»** (учётные данные доступа, полученные после входа в консоль, а не ключ вызова моделей), а поле баланса заполните согласно структуре ответа эндпоинта.

#### Пример 3: OpenAI-совместимый транзитный узел с единственным ключом

- Токен: ключ `sk-`, используемый для вызова моделей
- Обычно сопоставляется автоматически; если совпадения нет, добавьте адрес запроса баланса и поле баланса (например, `$balance` или `$data.balance`).

> Примечание: если адрес запроса баланса оставить пустым, баланс этой платформы не запрашивается, но она всё равно участвует в тарификации по множителю стоимости.

## Известные ограничения

- Самый быстрый / самый медленный TTFT и скорость берутся из новой проекции на стороне хоста: **вы должны полностью закрыть и перезапустить DSH**, прежде чем она начнёт собирать данные
- Модель без цены не тарифицируется; добавление цены задним числом заполняет её ранние вызовы
- Обновление в один клик полагается на `pnpm`: настольное приложение использует копию, поставляемую с хостом, тогда как использование через CLI / web требует `pnpm` в системе. Если ни один не найден, обновление сообщает об этом явно **и записывает каждое испробованное расположение**; вы также можете указать ему конкретную команду с помощью переменной окружения `DSH_DESKTOP_STATUSBAR_PNPM`

## Разрешения и внешний доступ

Плагин читает журналы сессий и локальную конфигурацию для вычисления использования, баланса и стоимости, а также поддерживает самообновление в один клик, поэтому это **высокопривилегированный плагин**. Ниже приведена реальная граница разрешений (соответствующая коду `lib/`). Пожалуйста, ознакомьтесь с ней перед установкой.

### Файлы

| Путь | Назначение | Примечания |
| --- | --- | --- |
| `<DSH_HOME>/dsh-status-bar/usage-ledger.json` | Локальный журнал использования, заполняется из истории при запуске | Запись только внутри собственного каталога плагина |
| `<DSH_HOME>/dsh-status-bar/holidays.json` | Кэш государственных праздников | Записывается при автоматических обновлениях праздников в фоновом режиме |
| `<DSH_HOME>/dsh-status-bar/exchange-rate.json` | Ежедневный кэш курсов валют | Записывается при обновлении курсов в фоновом режиме |
| `<DSH_HOME>/dsh-status-bar/tip-diag.log` | Журнал диагностики | Записывает диагностику позиционирования подсказок для поиска проблем |
| `<DSH_HOME>/dsh-status-bar/relay-balance.json` | Конфигурация баланса релея (без секрета в открытом виде) | Каталог плагина |
| `<DSH_HOME>/sessions` | Чтение журналов сессий для вычисления статистики токенов / стоимости | Только чтение |
| `<DSH_HOME>/.credentials.yaml` | Читает ключи API только по ссылкам, когда ни служба учётных данных, ни переменные окружения не предоставляют их | Только чтение |
| Профиль `package.json` / `pnpm-lock.yaml` / `pnpm-workspace.yaml` | Резервируется и перезаписывается при самообновлении в один клик | Только при нажатии «обновление в один клик» |

### Учётные данные

- Сначала используется служба учётных данных хоста `ctx.credentials` (авторитетный источник, записываемый страницей моделей); если она недоступна, происходит переход к переменным окружения (например, `DEEPSEEK_API_KEY` и имя ссылок каждого адаптера), затем к разделу ссылок `<DSH_HOME>/.credentials.yaml`.
- Ключи API **используются только для запроса баланса этой платформы**; они никогда не загружаются в другое место, не регистрируются в журналах и не записываются в журнал использования.
- Страница настроек показывает токены в виде точек с выбором для копирования; `GET /dsh-desktop-statusbar/api/relay-balance-config` возвращает токен того же источника во фронтенд. Эта конечная точка доступна только через loopback (проверки Host / Origin / remoteAddress) и никогда не покидает машину.

### Команды

- `pnpm` вызывается только при нажатии «обновление в один клик»: предпочтение отдаётся pnpm, поставляемому с хостом (например, `runtime/primary-runtime/dependencies/pnpm/bin/pnpm.mjs`), с откатом к системному `pnpm`; вы можете указать его с помощью переменной окружения `DSH_DESKTOP_STATUSBAR_PNPM`.
- При сбое обновление восстанавливает резервную копию профиля и показывает причину; если pnpm не найден, оно сообщает об этом явно и записывает каждое испробованное расположение.

### Границы отказов

- Нет учётных данных: баланс этой платформы показывает «—»; остальные поля продолжают работать.
- Сбой сети / тайм-аут: затрагивается только этот баланс или курс; остальная статистика не затронута.
- pnpm не найден: обновление в один клик явно выдаёт ошибку, а не завершается молча.
- Сбой самообновления: восстанавливается резервная копия `package.json` / файла блокировки профиля.

### Известные риски

- Высокопривилегированный плагин (чтение/запись файлов + сеть + учётные данные + команды) — примите решение об установке, ознакомившись с объёмом разрешений.
- Когда внешние службы баланса недоступны, соответствующие числа отсутствуют или устарели.
- Самообновление в один клик требует доступа на запись в каталог профиля.

## Разработка

Каждый тест — это отдельный скрипт, предназначенный для запуска с помощью обычного node — без фреймворка тестирования.

```powershell
npm test          # runs every verify*.js/.mjs under tests/, then checks project vs installed plugin dir
npm run sync      # copies lib/ into the installed plugin dir
```

Скрипты разработки в `tools/` поставляются с пакетом (поле `files` включает их),
поэтому и git-клон, и npm-установка получают их:

| Скрипт | Назначение |
|---|---|
| `tools/test.cjs` | полный прогон тестов + проверка согласованности |
| `tools/sync-to-plugin.cjs` | проект `lib/` → каталог установленного плагина |
| `tools/sync-from-plugin.cjs` | каталог установленного плагина → проект `lib/` |
| `tools/plugin-dir.cjs` | находит каталог плагина |
| `tools/shot.cjs` | перегенерирует скриншоты README |

Они используются только во время разработки; плагин никогда не загружает их во время выполнения.
npm-пакет включает `tests/` и `tools/`, поэтому установленная копия может напрямую запускать
`node tools/test.cjs` (полный прогон тестов + проверка согласованности).

Каталог плагина определяется автоматически: переменная окружения `DSH_STATUS_BAR_PLUGIN_DIR` →
известные структуры в `~/.dsh` (`local-plugins/`, каждый `profiles/*/node_modules/`) → выводится из расположения
`tools/`. При смене машины или имени пользователя изменения кода не требуются.
